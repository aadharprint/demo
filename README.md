# Ojas Print Service & Tools Studio (v6.0)

- `/templates/`: Separate printable HTML files for Caste, Domicile, and all 9 Annexures.
- `/images/`: Folder for `logo.png` and city stamp PNGs (`baraut.png`, `baghpat.png`, `kairana.png`, `shamli.png`, `ghaziabad.png`, `muzaffarnagar.png`, `saharanpur.png`, `meerut.png`, `stamp.png`).
- `/js/`: Complete frontend & admin logic.
- `/api/`: Payment order & webhook serverless functions.
